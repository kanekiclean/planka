# Планка

Тихий вечерний дневник. Перед сном пишешь пару строк о том, что успел, а ИИ разбивает день на задачи и оценивает каждую **относительно тебя** — твоего уровня и целей, а не среднего человека. Итог дня считается в процентах от твоей личной нормы.

## Что внутри

- **Вечерний ритуал.** Пишешь день как другу, отмечаешь настроение — ИИ раскладывает на задачи, ставит сложность, затраты сил и вклад в цели. Оценку можно поправить («Завысил / В точку / Занизил»), и ИИ подстраивается под твою шкалу.
- **Личная норма.** Медиана очков за последние 14 закрытых дней. Первые дни считаются от стартовой нормы.
- **Проекты.** Страница на большое дело: заголовки с крупными номерами, текст, фото, галереи, чек-листы, таблицы, плашки с цифрами, цитаты. Блоки перетаскиваются. ИИ предлагает структуру, считает прогресс и собирает страницу из документа Word.
- **Архив месяцев.** Обложка на каждый месяц, календарь-«пилюли», лучший день, куда ушли очки.
- **Карточки для отправки.** Итог дня, месяца или проекта — красивой картинкой в Telegram.
- **Темы.** Пять тем с фото и палитрой, плюс своя тема из любого фото — цвета подбираются автоматически.
- **Офлайн.** Приложение открывается без интернета; ИИ, конечно, нужен онлайн.

## Как установить на телефон

Открой ссылку на приложение, затем:

- **iPhone:** в Safari нажми «Поделиться» → «На экран Домой».
- **Android:** в Chrome открой меню (три точки) → «Установить приложение» или «Добавить на главный экран».

## Ключ для ИИ

ИИ работает через [OpenRouter](https://openrouter.ai): там есть бесплатные модели.

1. Зайди на [openrouter.ai/keys](https://openrouter.ai/keys) и войди через Google или почту.
2. Нажми «Create Key» и скопируй ключ (начинается с `sk-or-`).
3. Вставь его при первом запуске или в настройках.

У бесплатных моделей есть дневной лимит запросов (на вечернюю оценку дня хватает с запасом). Ключ хранится только на телефоне и отправляется напрямую в OpenRouter.

Модель выбирается автоматически: приложение берёт первую доступную бесплатную модель по списку предпочтений из `config.json`. Список можно менять без обновления приложения — просто поправить файл в репозитории.

## Данные

Все записи, проекты и фото хранятся только на устройстве (IndexedDB). Сервера нет. В настройках есть «Сохранить копию данных» и «Восстановить из копии» — так можно перенести всё на другой телефон.

## Публикация на GitHub Pages

1. Создай публичный репозиторий и загрузи в него содержимое этой папки (так, чтобы `index.html` лежал в корне).
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)` → **Save**.
3. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

Сборка не нужна — это обычные HTML, CSS и JavaScript.
